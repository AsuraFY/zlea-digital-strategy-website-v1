# ZLEA Digital Safety V1

Static prototype built with:
- HTML5
- Bootstrap 5
- Custom CSS
- Vanilla JavaScript

Included in this prototype:
- Responsive homepage
- EN / FR language switcher
- Get Help scenarios
- Resource cards
- Consultation form placeholder
- Newsletter placeholder
- About section
- Prototype Digital Safety Assistant chatbot UI

Important:
- The form does not send or store data.
- The newsletter button is not connected.
- The chatbot is scripted and local only.
- Booking/payment integrations are not included yet.

To run:
Open index.html in a browser. For best results, use a simple local server such as VS Code Live Server.
